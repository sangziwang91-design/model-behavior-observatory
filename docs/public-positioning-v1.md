# Public Positioning v1

## Public identity

**AI Behavioral Evaluation and Runtime Safety Audit**

## Method label

**Black-Box Behavioral Cartography**

## One-line statement

I study how observable AI behavior changes across structured interaction conditions.

## What this means

This work does not rank models only by final answers. It studies response trajectories: how outputs stabilize, drift, over-complete, imitate confidence, lose grounding, become measurement-invalid, or recover after interruption.

## Public expression rule

Public writing should lead with:

1. observable behavior;
2. method;
3. evidence;
4. limits;
5. reproducible public subset.

Internal project names may appear as project-line notes, but should not be the first explanation.
